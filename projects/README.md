# projects/

Um ficheiro por produto, `<nome>.md`, de `templates/project.md`. É o estado do projeto:
dono, destino, onde está, decisões, por decidir, próximos passos. Lê-se para retomar um
produto depois de tempo sem lhe tocar; o `products/<nome>/NOTES.md` é para retomar entre
sessões seguidas.

Separar os dois evita que o `NOTES.md` cresça com estado estratégico e que o estado do
projeto se perca em notas de sessão.
